# Public showcase rules

Avoid em dashes. This repository is public. Never import private source, client identifiers, ticket numbers, raw receipts, recordings or private history. Use invented fixtures. Case summaries are anonymized and author-reported. Do not invent attestations. Preserve human release approval boundaries. Use npm run release:push for updates; it performs calendar version iteration and privacy checks. Do not bypass hooks. Do not deploy the website or send communications unless explicitly requested.
